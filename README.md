Well i made this project based on real-time planetary defense and space telementary dashboard , featuring an interactive 3D solar system view. 
AEGIS contains Nasa Api key , hosted on nest , tracks near earth asteroids , solar flares , geomagnetic storms , and the International Space station (ISS) in real time 

Well i added some festures via NASA NeoWs. Shows close-approach distance (in-lunar distances) , relative velocity , and flags potentially hazardous space rocks.

# Tech Stack
**frontend** : react , Vite , Three.js , tailwind CSS
**Backend** : Node.js , express , SQLite
**Api keys**: NASA NeoWs , NASA DONKI , NOAA Space weather ,

**AI used in this project** : for UI , plan , hosting purposes , 3D Earth presentation .
